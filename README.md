# 听写小站 · OwnClass

一份词表，多种练法。网页报词，孩子用纸笔写，结束后自主核对并重练错词。

支持读汉语写英语、读英语写英语、读英语写汉语、语文听写、看拼音写词语五种模式。可以直接粘贴文字、导入 JSON，或上传图片识别后人工核对；也可以交给自己的 AI／MCP 创建待确认草稿。任务优先采用有来源许可的真人录音，未命中时明确使用合成兜底；图片识别和服务端合成语音均为可选项。

## 在线体验

体验地址：<https://ownclass.top/tingxie/>（家长端与孩子听写区同一入口；首次使用在页面注册账号）。

## 本地运行

需要 Node.js 24+、pnpm 12.6.0。

```sh
pnpm install
pnpm build
pnpm start
```

打开 `http://127.0.0.1:8083/`。可复制 `.env.example` 为 `.env` 配置 OCR、端口、数据目录等。首次打开创建账号，之后登录使用。一个账号一个词库，读写均按账号隔离；设置 ALLOW_REGISTRATION=false 可关闭注册。

开发用两个终端分别运行 `pnpm dev`（API，8083）与 `pnpm dev:web`（前端，5198）。前端使用相对资源和 API 地址，支持 `/tingxie/` 子路径，配置见 [部署说明](DEPLOY.md)。

## 使用流程（家长端与孩子听写区双端闭环）

双端职责、6 态任务状态机与孩子入口设计详见 [双端架构与完整功能规范](docs/双端架构与完整功能规范.md)。

1. **新建与整理词表（家长端）**：粘贴原文、JSON、选择图片 OCR 或通过 AI 提示词／MCP 导入草稿。在单行列表式编辑器中逐项核对中英词义、拼音与发音状态 badge，支持整表预检与单行试听。
2. **一键派发任务（家长端）**：在词表详情或今日任务页选择练法、编号范围（支持全选／区间快捷选词）、语速、是否穿插待巩固旧词及是否允许孩子交卷后自主核对，一键派发到孩子听写区。
3. **跨设备进入孩子听写区（`?child=1`）**：家长端点击顶部“孩子听写区 ↗”获取免密二维码或专属链接（基于高熵 `childToken` 白名单鉴权，首次打开自动抹除地址栏参数，支持一键重置链接），在平板或新窗口独立进入学生工作台。
4. **独立专注听写（孩子端）**：孩子端包含 **01 今日听写任务**、**02 批改结果与错词订正**、**03 自主磨耳朵（纯听与跟读）** 三大板块。声音准备在家长端进行；孩子可直接开始，已准备的音频按词读取，未准备或读取失败时使用机器朗读。做题进度按词实时同步服务端并支持跨设备租约接管，写完后一键交卷。
5. **试卷批改与错词重派（家长端）**：孩子交卷后家长端轮询后置顶提醒，支持“只点错词”四态判分（正确／待巩固／不确定／未核对）、一键退回重做、以及错词一键重新派发。
6. **纸面订正与隔日掌握（孩子端 + 待巩固池）**：批改确认的错词与不确定项按练法自动进入待巩固池，默认在 3 个不同日期独立听写通过后标记掌握；孩子在学生端点击“我已订正”仅记录纸面订正打卡，不增加掌握次数。

## 今日任务与使用边界

家长端（`./`）仅负责词表准备、任务派发、实时进度监控、A4 练习纸打印与试卷批改，听写操作集中在孩子区。孩子听写区（`./?child=1`）使用现有孩子接口白名单：

- 任务遵循 6 态生命周期：`pending（待开始） → in_progress（进行中） → submitted（已交卷待批改） → completed（已批改）` 及 `withdrawn（已撤回） / expired（已过期）`，同一时刻仅允许 1 个任务处于 `in_progress`。
- 派发时固化词表内容与音频快照，后续修改或删除原词表不影响已派发任务与历史记录。
- 听写投影省略答案字段（`answer` / `alt`），保留设备朗读所需原文；存在待完成或待批改任务时，“磨耳朵”界面隐藏待考词文字。接口仍含朗读文本，这是自主练习工具，不承诺考试级防作弊。
- 已交卷任务由家长退回后继续补写或从头重写；已批改任务通过复制新任务再练，保留原记录。交卷失败会明确提示并允许重试。

## 纸张与陪练

任务支持打印 **A4 紧凑三栏排版** 的听写空白纸、看拼音写词语纸和待巩固练习纸（20–30 词稳妥排入单张 A4 纸，长句自动跨满整行），默认不附答案页；系统打印窗口可另存 PDF。批改完成自动生成 PNG 汇报卡，可在本机加入书写纸照片并保存分享。

默认每五项小休息，长词／句子的自动间隔会适当延长；可改为不分组或关闭自动间隔。累计活动二十分钟会在项间提示休息。

## 自带 AI 与 MCP

家长端“连接与账号”可创建带最小权限（`wordlists:read`、`drafts:write`）的令牌，同时提供 **远程 HTTP MCP 配置**、**本地 `stdio` MCP 配置** 与 **REST API 示例**，让支持 MCP 的客户端读取格式、校验、建草稿和复用自己的词表。草稿经网页核对后才成为正式内容。配置、权限和纯 API 用法见 [AI 接入](docs/AI接入.md)。未使用 MCP 时，仍可复制结构化提示词（含词表名称、年级、单元、教材来源）和粘贴 JSON。

## 技术结构

- `packages/contract`：Zod 数据契约及推导类型，`schema/wordlist.schema.json` 是生成的交换格式 schema。
- `packages/core`：纯 TypeScript 导入解析、校验提醒、播放生命周期和错词合并。
- `apps/server`：Hono + Drizzle + better-sqlite3；OCR/TTS 由服务端适配器调用。
- `apps/web`：React + Vite + TypeScript，移动端逐词编辑、本机草稿和听写进度。
- `apps/server/drizzle`：drizzle-kit 生成的迁移；`pnpm db:generate` 生成结构变更。

数据默认存放在 `data/dictation.db` 与 `data/audio/`。本轮不迁移旧版数据：使用空 DATA_DIR 开始，不导入旧 JSON。写入落盘后才确认成功，编辑和删除通过 revision 防止陈旧覆盖。

## 验证

开发、提交与协作请先读 [开发与交付流程](CONTRIBUTING.md)；AI 代理须遵守 [AGENTS.md](AGENTS.md)。每项独立任务默认完成验证、提交、推送和 PR，多对话并行使用独立 worktree；合并与线上部署分别确认状态。

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm schema:export
pnpm build
pnpm exec playwright install chromium webkit
pnpm e2e
```

单元/接口测试使用临时目录，浏览器测试使用独立临时数据库与 8898 端口。OCR/TTS 测试使用合成适配器；浏览器测试模拟朗读事件，不能替代目标设备的真实发音和 iOS 播放验收。

## 与 OwnClass 的关系

本轮是独立工具重构，尚未接入主项目账号、课程布置或学情记录。未来先用入口跳转和版本化 JSON 关联，再迁入主项目现有契约、路由与权限体系，详见[重构方案](docs/TypeScript重构方案.md)。

词表与答案仅本账号可读写，OCR 原文不在词表响应或导出中下发。它仍是自主练习工具，不能直接充当主项目的考试接口。后续任务与复习安排见[开发计划](docs/听写小站开发计划.md)，当前进度见[实施记录](docs/实施进度.md)。

Your data. Your way. All for learning.

## 纯听与跟读

打开词表可选择“纯听这份词表”或“跟读练口语”。纯听支持顺序、打乱、循环和中英交替；跟读支持示范、本机录音和回放比较。录音不上传，离开页面即清除，不参与评分或掌握状态。麦克风需要 HTTPS（本机 localhost 除外）及浏览器授权。后台、锁屏播放由系统决定，尚未承诺手机全平台支持。
