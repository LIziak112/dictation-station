## Scope and coverage

## Verification

- `pnpm test`：13 个测试文件、57 项通过，覆盖任务单活、退回保留 / 重置、清除批改、完成不可重开、其余正确、随机抽查，以及原有音频 / 学习规则。
- `pnpm lint`、`pnpm typecheck`、`pnpm schema:export`、`pnpm build`：通过。构建仍有既有约 517KB 主包提示，本轮未扩展为拆包工作。
- `pnpm e2e`：覆盖完整 Chromium / WebKit 回归。Windows WebKit 缺少系统 TTS，测试只补合成结束事件；WebKit 单独设置 60 秒流程 / 15 秒断言预算，未删减原操作或放宽数据断言。全量运行 43 / 44 通过；跨设备用例运行中重建导致旧资源 404，随后固定产物重跑，又在到达家长批改提醒后耗尽 60 秒，单独增加多上下文长流程预算后复验通过（72 秒）。这是分轮验证结果，未将单次全量运行描述为全绿。
- `pnpm exec playwright test e2e/mobile-flow.spec.ts e2e/ui-polish.spec.ts`：最终窄屏和界面复验中，手机流程 4 项及界面专项 8 项全部通过；320×844、390×844 的 10 个页面有无横向溢出断言和截图。包括暂停返回后继续第 2 项、交卷 503 后恢复、真实词文本进入朗读队列、批改 / 订正、默认无打印答案。
- 手工查看最终手机截图：听写按钮完整、编辑导入区折叠、纯听待考词短标题、批改按钮、错误恢复。选取截图：[320px 听写](screenshots/mobile/player-320.png)、[320px 编辑](screenshots/mobile/editor-320.png)、[交卷失败恢复](screenshots/mobile/submit-error-320.png)、[390px 批改](screenshots/mobile/review-390.png)。

**Not verified**：真实 iPhone / Android 硬件、软键盘与浏览器工具栏、实际系统发音 / 音质 / 自动播放、麦克风、锁屏与后台、读屏软件、原生浏览器 200% 缩放（自动化使用双倍字号）、RTL / 多语言、实际打印机和原生分享。AI 连接、全部历史页面和每个异常分支未做逐屏视觉验收，不将本报告扩大为全站认证。

最终结果：57 项单元 / 接口测试通过；原有 44 项浏览器用例经全量与受影响项复验均有通过记录，新增孩子入口失败恢复用例在两种浏览器通过（共 46 个不同浏览器用例）。最后一轮手机流程 4 项、界面专项 8 项、Chromium 跨设备 1 项通过；`pnpm exec playwright test e2e/tasks.spec.ts --project=webkit --output=test-results-task-final` 单独复验 1 项通过。
