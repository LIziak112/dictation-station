## B 的人工验证方法

1. 空 DATA_DIR 启动，页面注册并创建词表；刷新仍已登录。
2. 独立浏览器登录同账号，可读取该词表；新建另一账号，词库为空，原词表链接返回不存在。
3. 编辑一份未保存草稿，退出并换账号不可见；登录原账号可恢复，不为清缓存删除未同步内容。
4. 修改密码后其他设备会话失效；部署者重设密码结果相同。
5. 本账号链接／二维码只用于已登录的同账号设备，不再对外公开词表。
6. 配置可选服务端 TTS 后准备音频，本账号可播放；未登录或另一账号直接访问音频不可读取。

B 阶段交付时尚未包含云端任务和历史，后续已在 C／D 阶段补齐。浏览器自动化中的合成语音不等于真机发音验收。

## I：双端角色隔离、6 态任务状态机与 `childToken` 白名单（2026-11-03）

- **家长端与孩子听写区严格隔离**：家长端（`./`）专注词库整理、整表／单行试听预检、任务派发、进度监控、A4 练习纸打印与试卷批改，移除家长端直接开始听写的入口；孩子听写区（`./?child=1`）独立承载 **01 今日听写任务**、**02 批改结果与错词订正**、**03 自主磨耳朵（纯听与跟读）** 三大板块。
- **6 态任务状态机与并发控制**：实现 `pending → in_progress → submitted → completed` 及 `withdrawn / expired` 完整流转；单任务 `in_progress` 互斥、进行中禁止编辑、强制撤回二次确认并保留 `interruptedAt` 中断记录、跨设备 `activeDeviceId`／`heartbeatAt` 心跳租约与接管、过期任务一键改期重派。
- **批改防阻塞与掌握闭环**：四态判分（`correct` / `wrong` / `uncertain` / `unchecked`），`wrong` 与 `uncertain` 均自动进入待巩固池；支持可选 `allowSelfReview`（孩子自评 + 随机抽取 1–2 个 `spotCheckWordIds` 供家长抽查）、家长一键退回重做（`returnForRedo`）、错词一键再派发（`redispatchWrong`）；“我已订正”与多日独立掌握 `streak` 严格解耦。
- **`childToken` 白名单与防泄密**：实现高熵 `childToken` 生成、SHA-256 哈希存储、一键重置、首次访问 `history.replaceState` 抹除地址栏参数、Deny-by-Default 路由白名单中间件；交卷前剥离答案字段，且当存在未完成或进行中任务时自动遮罩“磨耳朵”板块中待考词的中英拼写文字。
- **词表表格编辑、AI/MCP 与 A4 三栏打印**：编辑器升级为四列单行列表并实时展示发音状态 badge；AI 提示词明确要求词表名称、年级、单元、教材来源；连接页提供 HTTP MCP、stdio MCP 与 REST API 配置；打印页支持全选／区间选择与 A4 三栏紧凑排版（`blank` / `pinyin` / `review`）。
