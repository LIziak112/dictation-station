# 手机屏幕与系统验收边界

代码与自动化已覆盖浏览器前台流程。当前执行环境为 Windows，没有连接 iPhone 或 Android；以下硬件项保持未验证，不推定已通过。

## 手机屏幕验收

使用 Playwright 设置 320×844、390×844 的手机宽度，在 Chromium 与 Windows WebKit 中检查：家长今日页、安排任务、词表编辑、孩子首页、磨耳朵、听写、交卷错误恢复、批改、打印预览和订正。每页断言无横向溢出并截图；主按钮纵排，词条输入 computed font-size ≥16px。重点人工复看听写、编辑、磨耳朵和批改的最终截图。

这属于移动浏览器视口验收，不是实际 iPhone / Android 的系统验收。实际播放测试使用合成事件；不能由此认定语音音质、自动播放、软键盘或麦克风已通过。
