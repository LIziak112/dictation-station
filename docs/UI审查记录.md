# 听写小站综合界面审查

日期：2026-11-03。按 better-interface 和 better-accessibility、better-layout、better-writing、better-typography、better-colors、better-ui 六个领域执行审查并修复。用户所写 better-inf 在本机没有独立技能文件，使用对应的综合界面技能 better-interface。

## 范围与覆盖

范围为整个独立听写前端：词表首页、空态与筛选、导入/编辑/试听、模式与设置、播放、核对、分享、本机稿错误与网络失败。是完整流程审查，不是按 PR diff 推断的变更审查。

技术为 React、原生 HTML 控件、项目 CSS 语义 token、lucide 图标；保留原有绿色主题与字号层级，不引入新字体、组件库或依赖。本仓库未找到 AGENTS.md、CLAUDE.md、CONTRIBUTING.md 或独立设计系统文件；依据用户提供的项目全局要求、README、WORDLIST-SPEC 和既有重构方案。

## 验证

- `pnpm lint`、`pnpm typecheck`、`pnpm test`：通过，单元/接口仍为 23 项。
- `pnpm build`：前后端构建通过。
- `pnpm e2e`：12 项通过，Chromium 6 项、WebKit 6 项。覆盖完整听写流程、保存失败保稿、损坏稿原样导出，以及新增的键盘切页、标题/焦点、错误定位、撤销、清除搜索、200% 字体和核对页空格键不播放、保存期间焦点保留/输入锁定，以及离开后的迟到回执不抢回当前页。
- 实际浏览器检查：320/768/1440px 下编辑页 scrollWidth 与视口一致；RTL 压力重排未溢出；reduced-motion 下按钮 transition 为 0s、transform 为 none；首个无效中文输入框获得焦点且有描述，顶部约 317px，没有被顶栏遮住。
- 实际渲染取色：编辑页 52 个可见文本节点最低 5.18:1，无低于 4.5:1 的结果。次要文字 `#606b63` / 卡片 `#fffefa` 为 5.50:1，白字 / 主按钮 `#28634e` 为 7.04:1，错误文字 `#a13229` / 卡片为 6.93:1，边界 `#879488` / 卡片为 3.14:1。
- 已查看桌面首页、编辑/播放页和 WebKit 320px + 200% 字体截图。没有承诺 RTL 翻译、黑暗模式或屏幕阅读器完整认证。

**Not verified**：NVDA/VoiceOver 实际播报、真实手机键盘与系统放大、Pencil、扬声器声音、多音字与真实 OCR/TTS。自动化语音仍使用合成事件，不代替目标设备验收。
