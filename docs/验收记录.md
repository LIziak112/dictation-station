## 三轮审查

1. 简化：删除旧 DOM 页面和按源码切片执行的测试；拆分首页、详情、编辑、播放；纯领域逻辑不依赖 React/数据库；二维码改由本地打包依赖生成。
2. 正确性：修复提前确认落盘、坏文件被当作空库、陈旧更新覆盖、未知版本误解析、重复 ID、文本超限、编辑短语空格被去除、部分重练清掉其他错词、迟到请求回写和停止后的旧播放回调。存储/解析问题均先补失败测试。
3. 数据边界：公开接口仍是完整练习词表，不冒充受限考试接口；OCR 原文不在公开响应/导出中；口令不进分享链接；外部凭据只在服务端；图片识别/服务器语音显式触发；默认设备朗读不会调用服务器语音。没有修改主项目的学生答案保护。

## 限制与人工验收

- 浏览器朗读事件被模拟，不能证明真实扬声器声音、多音字发音或 iOS 自动播放行为；OCR/TTS 外部调用使用合成适配器，没有消费真实服务。
- 尚未在手机/iPad 真机验收系统键盘、后台和语音行为；手动步骤见 DEPLOY.md。
- 本轮不提供账号/课程/作业关联、跨设备练习记录、完整离线启动、音频自动清理或定时备份。
- 本机保留最近一次听写会话；词表与旧分享 ID 保留。旧语速偏好兼容读取，旧版仅保存在浏览器的错词标记未自动迁入新会话，旧 localStorage 原值不删除。
- 部署方式改为安装依赖并构建后启动，不能沿用只上传 server.js/public 的发布方式；SQLite 升级前备份和回退要求见 DEPLOY.md。

任务所列 task-workflow、writing-plans、systematic-debugging、simplify、code-review、security-review、verification-before-completion 技能未在环境中提供；以上是实际执行的等效检查，没有声称运行这些技能。移动端与界面实现参考 mobile-native、better-ui；真机边界保留人工验收。
