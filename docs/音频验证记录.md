# 音频验证记录

日期：2026-11-03。来源与许可见 [SOURCES.md](../SOURCES.md)。验证脚本：pnpm exec tsx scripts/probe-audio.ts；独立临时目录保存 JSON 报告与获准缓存的样本，不触碰用户数据，不在 CI 调用公开网络。

## 实际结果

公开词典 JSON 可用；其 /media/pronunciations 中转地址实测 502，不能直接作为可播放证据。转用同一条目提供的 Commons 来源页，读取原文件、作者与许可后再下载。原始 school 录音在本机 Chromium 实际播放完成，时长约 1.303 秒；本机 WebKit 对该 Ogg 文件报媒体错误，应用需走合成兜底。这不是 iPhone 真机验证。

第二轮 12 项样本的结果如下，只代表当次网络与指定英音条件，不是整体覆盖率：

| 样本                           | 当次结果                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| apple、school、beautiful、read | 匹配并下载英音真人原文件，CC BY 3.0 US，作者 Association Shtooka, Judith Franck            |
| 太阳（tài yáng）               | 匹配并下载普通话真人录音，CC BY 2.0 FR，作者 Wei Gao, Vion Nicolas                         |
| record、look after             | 指定英音未匹配，明确设备合成兜底；不把其他口音算作英音                                     |
| I go to school on foot.        | 未匹配整句录音，合成兜底                                                                   |
| 音乐、银行                     | 元数据存在，但当轮原文件读取失败，合成兜底；第一次英语样本也出现超时，说明必须容许网络波动 |
| 长大、行走                     | 指定拼音未匹配有效录音，合成兜底                                                           |

中文匹配同时核对拼音、来源中文描述与普通话录音分类，不把拼音相同的其他汉字或单字拼接当作整词。缺少带调拼音或明确读音 ID 时不猜测，使用透明兜底。

## 自动化覆盖

合成适配器测试覆盖真实音频与作者／许可投影、未命中、指定读音、中文同音异字拒绝、本地词书、按口音处理。浏览器测试覆盖文件无法解码后请求合成、覆盖计数如实更新。没有把合成测试文件称作真人发音验收。

真实 iPhone／Android 的声音、锁屏、蓝牙与音量仍需实机验收，当前只确认桌面浏览器与可预期的降级路径。
